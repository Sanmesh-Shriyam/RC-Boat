# RC-Boat
Remote control boat for a race boat



This is a basic Remote Controlled Boat Project

#Materials Required
1.High Torque Motor
2.Servo
3.Boat propellent Shaft
4.3D printed boat
5.Motor Relay
6.Power Bank
7.Battery pack(12V x 6 battries)
8.Connecting wires
9.PS 3 Controller
10.ESP32
11.Switch

#Connections
1.Connect the ESP32 to the power bank.
2.Connect all the 12V 6 batteries together in series to make a battery pack.
3.connect the battery pack to the motor relay with a switch in between.
4.connect the power wire of servo to the motor relay.
5.Connect the Motor to the relay.
6.Make the digital pin connections as written in the code.
